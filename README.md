# Личное инфо

База учебных конспектов: **Глава → Тема → Ветка → Карточка**, а внутри карточки —
**блоки** с цветными метками терминов, текстом и фотографиями.

Один код работает и как обычный сайт, и как Telegram Mini App.

<!-- ────────────────────────────────────────────────────────────────────── -->

## Что умеет

| | |
|---|---|
| **Структура** | Дерево произвольной глубины. По умолчанию четыре уровня, но пятый добавится без правок схемы |
| **Карточка** | Состоит из блоков. Каждый блок — отдельный термин со своей меткой, своим текстом и своими фото. Дополнять «именно ТПО» = править ровно один блок. Блоки сворачиваются: видно только метки, открываешь нужный |
| **Метки** | Три цвета: 🔴 красный, 🟢 зелёный, 🟡 золотой. Смысл цветов настраивается в одном месте |
| **Редактор** | Жирный, курсив, заголовки, списки, цитаты, ссылки. Фото — кнопкой, вставкой из буфера или перетаскиванием |
| **Поиск** | Полнотекстовый по-русски: и по названиям, и по тексту блоков. Открывается на `⌘K` / `Ctrl+K` или клавишей `/` |
| **Темы** | Белая, тёмная, розовая |
| **Размер текста** | Пять ступеней от 90 % до 150 %, настройка своя на каждом устройстве |
| **Приложение** | Ставится на телефон и компьютер значком с экрана «Домой» — отдельный установщик не нужен |
| **Без интернета** | Открытые страницы сохраняются сами, кнопка «Скачать» кладёт в память сразу все карточки с фотографиями |
| **Фон** | Векторные пионы, лепестки, мягкое сияние — или своё фото. Насыщенность и размытие регулируются |
| **Права** | Читают все без входа. Пишет только тот, кто есть в таблице `editors` |
| **Порядок и названия** | Стрелки ↑ ↓ и карандаш прямо на карточках списка: переставили — сразу видно, куда переехало |
| **История** | Каждая правка блока сохраняется в `block_revisions` — старую версию можно достать |
| **Telegram** | Тема, системная кнопка «назад», хаптика, безопасные зоны |

## Быстрый старт

```bash
npm install
cp .env.example .env.local     # подставить ключи Supabase
npm run dev
```

Без ключей приложение покажет экран с инструкцией — это нормально.

Подробная настройка (Supabase, права редактора, деплой, Telegram-бот) —
**[docs/SETUP.md](docs/SETUP.md)**.

Vite 8 · React 19 · TypeScript · Tailwind 4 · TipTap 3 · Supabase (Postgres + Auth + Storage)
